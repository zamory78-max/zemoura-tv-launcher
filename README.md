# لاونشر التلفاز (TV Launcher)

لاونشر مخصص لأجهزة **TV Box** التي تعمل بنظام Android — واجهة عربية (RTL) تعمل بالريموت.

## المزايا

| الميزة | التفاصيل |
|---|---|
| تغيير الخلفية | 4 خلفيات جاهزة أو أي صورة من الجهاز (تُحفظ بعد إعادة التشغيل) |
| صفوف التطبيقات | صفوف أفقية بأسلوب Google TV، مع فتح بالريموت وضغط مطوّل للخيارات |
| **تحريك التطبيقات والمجلدات** | ضغطة مطولة ← «نقل»، ثم الأسهم لتغيير المكان، وOK للتثبيت. الترتيب يُحفظ بعد إعادة التشغيل |
| **التطبيقات غير المدعومة** | تظهر في صف منفصل بوسم «غير مدعوم» (تطبيقات الهاتف بلا واجهة Leanback). تُشغَّل من الإعدادات ← إظهار التطبيقات غير المدعومة |
| فيديوهات يوتيوب | صف فيديوهات الأكثر مشاهدة حسب البلد عبر YouTube Data API (يتطلب مفتاحاً مجانياً) |
| الحماية | رمز سري (بصمة مملحة + تأخير بعد المحاولات الخاطئة) لحماية الإعدادات والتطبيقات المقفلة والمجلدات |
| مجلدات مقفلة | مجلدات تحوي تطبيقات وملفات، يمكن قفلها بالرمز |
| الطقس | Open-Meteo، مع البحث عن أي مدينة |
| الصلاة | حساب محلي بمكتبة [Adhan](https://github.com/batoulapps/adhan-java)، مدينة وطريقة حساب ومذهب قابلة للتغيير |
| الأذان والعدّ التنازلي | شاشة أذان كاملة مع عدّ تنازلي للإقامة وكتم الصوت |
| البقاء كافتراضي | تعيين دور HOME + استقبال الإقلاع وانقطاع الكهرباء + إعادة جدولة الأذان |

## البناء

1. افتح المجلد في **Android Studio** (Koala أو أحدث) ودع Gradle يزامن المشروع، ثم Run.
2. أو من سطر الأوامر: `gradle assembleDebug` (يتطلب Android SDK 34 و JDK 17).
3. أو من GitHub: تبويب **Actions ← Build APK** ثم حمّل الـ APK من Artifacts.

### مفتاح يوتيوب (اختياري)
أنشئ مفتاح *YouTube Data API v3* من Google Cloud Console، ثم إما:
- ضعه في `gradle.properties`: `YOUTUBE_API_KEY=...`، أو
- أدخله من داخل اللاونشر: الإعدادات ← مفتاح YouTube Data API، أو
- أضفه كسر `YOUTUBE_API_KEY` في GitHub Actions.

### صوت الأذان
ضع ملفاً بصيغة `adhan.mp3` في `app/src/main/res/raw/` (لم يُضَف للمستودع لحقوق النشر).

## ملاحظات مهمة عن حدود أندرويد

- **التعيين كافتراضي:** لا يمكن لأي تطبيق جعل نفسه الافتراضي بصمت. الإعدادات ← «تعيين كلاونشر افتراضي» تفتح نافذة النظام. بعد ذلك يبدأ النظام اللاونشر تلقائياً عند كل إقلاع، حتى بعد انقطاع الكهرباء.
- **شاشة الأذان فوق التطبيقات:** تحتاج إذن «العرض فوق التطبيقات» وإذن المنبّهات الدقيقة (روابط في الإعدادات).
- **منع حذف التطبيقات:** لا يستطيع اللاونشر منع الحذف من خارجه؛ القفل يحمي التشغيل والإعدادات داخل اللاونشر. للحماية الكاملة استخدم وضع Kiosk/Device Owner.
- **التطبيقات غير المدعومة** قد لا تعمل بالريموت (تحتاج لمس)؛ يُنصح بتوصيل ماوس.
- **الفيديوهات** مدعومة حالياً من يوتيوب فقط؛ إضافة مصدر آخر تتم بتنفيذ مزوّد جديد في `VideoRepository`.
